This will be where I experiment with my current database set up and see what I can do.


Done in root folder to download package dependencies required for this project to work correctly
```
pip install -r requirements.txt
```

Then activate virtual environments on services folder

```
python -m venv venv
```

Then activate it:

Windows:
```
venv\Scripts\activate
```

Mac/Linux:
```
source venv/bin/activate
```
